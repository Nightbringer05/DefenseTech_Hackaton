Drone Sound Toolkit

Build 5-second FLAC training sets from the MAD military audio recordings, mapped onto the challenge's four classes, plus synthetic drones mixed over real backgrounds. Each dataset is written in the challenge's own folder layout, with matching 224×224 log-mel spectrograms, so the starter-kit trainer reads it unchanged. Below the builder you'll find a live rotor synth, notes on the libraries, and the Acoular flyby reference.

Dataset builder

MAD has no drones, so its recordings supply the three non-drone classes. drone_buzz comes from the synthesizer: each clip randomizes the drone, its flight and the mix, and is laid over a real non-drone recording. MAD training and the synthetic clips go into train/. MAD test becomes a held-out mad_test/ split. The real challenge valid/ split is copied in unchanged so the trainer still picks its threshold on real data.

Acoular
best fit verified 26.08

      
An acoustic beamforming library. Its MovingPointSource flies any signal along a Trajectory and renders what each microphone in an array hears, including Doppler shift and distance loss. To use it in the builder, select engine = acoular.

      
pip install acoular

      
Short snippet
traj = ac.Trajectory(points={0.0: (-75, 20, 30), 10.0: (75, 20, 30)})
src  = ac.MovingPointSource(signal=sig_gen, mics=mics,
                            trajectory=traj, conv_amp=True)
out  = np.concatenate(list(src.result(4096)))  # (N, n_mics)

pyroomacoustics
verified

      
Simulates rooms and open space with microphone arrays. It's strong on reverb, reflections and DOA algorithms, but sources stay fixed in place, so a flyby means stitching together short segments.

numpy / scipy synth
used here

      
A handwritten rotor model: BPF = blades × RPM / 60, harmonics for each rotor, a random walk on RPM and added noise. It's in dronesynth/sources.py and records exact RPM and BPF in every label row.

audiomentations
verified

      
Augmentation at training time: SNR mixing, pitch shift to simulate other motor speeds, gain, EQ and background clips. A GPU version is available as torch-audiomentations.

Real recordings
datasets

      
The MAD military audio set in MAD_dataset/ is the main source of real non-drone audio in the builder. By default, shooting and shelling map to explosion; vehicles, helicopters and jets map to vehicle_mechanical; and footsteps map to ambient_outdoor. Helicopters make good hard negatives because their rotors also produce harmonics. For real drone audio, see the datasets linked here.

not recommended

Acoular flyby

  
The reference script, also saved as synth/examples/acoular_flyby.py. It synthesizes a four-rotor drone, flies it past a 4-mic square array and writes a 4-channel WAV. The clips below came from this script.

examples/acoular_flyby.py


import acoular as ac  # import before numpy (Numba/OpenBLAS warning)
import numpy as np, soundfile as sf

FS = 22050
DUR = 10.0
t = np.arange(int(FS * DUR)) / FS

# 1) Synthesize a quadcopter: 4 rotors, 2 blades, slightly different RPMs + jitter
rng = np.random.default_rng(0)
sig = np.zeros_like(t)
for rpm in (5200, 5260, 5310, 5150):
    rpm_t = rpm + 60 * np.cumsum(rng.normal(0, 1, t.size)) / np.sqrt(FS)  # random walk
    phase = 2 * np.pi * np.cumsum(2 * rpm_t / 60) / FS                    # BPF phase
    for h in range(1, 9):
        sig += (1 / h) * np.sin(h * phase)
sig += 0.3 * rng.normal(size=t.size)          # broadband hiss
sig /= np.abs(sig).max()
sf.write("dry.wav", (0.9*sig).astype(np.float32), FS, subtype="PCM_16")

# 2) Mic array: 4 mics, 0.5 m square, on the ground
mics = ac.MicGeom(pos_total=np.array([[-.25, .25, -.25, .25],
                                      [-.25, -.25, .25, .25],
                                      [0, 0, 0, 0]]))

# 3) Straight flyby at 30 m altitude, 15 m/s
traj = ac.Trajectory(points={0.0: (-75.0, 20.0, 30.0), DUR: (75.0, 20.0, 30.0)})

src_sig = ac.GenericSignalGenerator(source=ac.TimeSamples(data=sig[:, None], sample_freq=FS))
moving = ac.MovingPointSource(signal=src_sig, mics=mics, trajectory=traj, conv_amp=True)

# 4) Pull blocks and write a 4-channel WAV (Doppler + 1/r included)
out = np.concatenate(list(moving.result(4096)))
out /= np.abs(out).max()
sf.write("flyby.wav", out.astype(np.float32), FS)
print(out.shape)   # (220500, 4)

      
Install with pip install acoular soundfile. Acoular 25 and later renamed several attributes, for example mpos_tot → pos_total and numsamples → num_samples, so older tutorials may not run unchanged.
